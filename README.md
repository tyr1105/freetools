# FreeTools 🛠️

Free online tools that work entirely in your browser. No signup, no upload, 100% private.

## Tools

- 🔊 [Text to Speech](text-to-speech.html) - Convert text to natural speech
- 🧾 [Invoice Generator](invoice-generator.html) - Create professional invoices, export PDF
- 📱 [QR Code Generator](qr-generator.html) - Generate custom QR codes
- 📝 [JSON Formatter](json-formatter.html) - Format, validate, minify JSON
- 🔐 [Password Generator](password-generator.html) - Generate strong passwords

## Features

- 100% client-side - your data never leaves your browser
- No signup required
- Works offline
- Mobile responsive
- Free forever

## Tech

- Vanilla HTML/CSS/JavaScript
- Tailwind CSS (CDN)
- jsPDF for invoice PDF generation
- QRCode.js for QR code generation
- Web Speech API for text-to-speech
